## Overview

`Paint::clip(Shape* clipper)` clips the photo Picture and status-badge Shape inside a profile card’s avatar Scene. The same objects are traced through every stage below.

```cpp
// photoPixels: decoded 16 × 12 pixels in ABGR8888.
auto background = Shape::gen();
background->appendRect(0, 0, 16, 12);
background->fill(232, 238, 241);

auto avatar = Scene::gen();
auto photo = Picture::gen();
photo->load(photoPixels, 16, 12, ColorSpace::ABGR8888, true);
auto badge = Shape::gen();
badge->appendCircle(12, 8.5, 2, 2);
badge->fill(35, 160, 100);
avatar->add(photo);
avatar->add(badge);

auto roundClip = Shape::gen();
roundClip->appendCircle(8, 5.5, 5, 5);
avatar->clip(roundClip);  // Paint::clip(Shape*)

canvas->add(background);
canvas->add(avatar);
canvas->update();
canvas->draw(true);
canvas->sync();
```

### The clipper's data

There is no separate `ClipperData` object in this implementation.

| Owner | Field / type | This example |
| --- | --- | --- |
| `avatar`'s `Paint::Impl` | `Shape* clipper` | References `roundClip`; the clip API retains it |
| `roundClip`'s `Paint::Impl` | `RenderData rd` (`void*`) | Receives the CPU `SwShapeTask` during Update |
| `SwShapeTask` | `bool clipper`, `SwShape shape` | Clipper mode is true; the circle produces `shape.rle` |
| `SwRle` | `Array<SwSpan> spans` | Each span stores `x`, `y`, `len`, and `coverage` |
| Photo / badge `SwTask` | `Array<RenderData> clips` | Both contain the same roundClip Task handle |

`SwShapeTask::clip(SwRle* target)` is the **internal CPU operation**, distinct from the public `Paint::clip(Shape*)`. It selects stroke RLE, a rectangle bounds fast path, or fill RLE. This circle has no stroke and uses fill RLE. The photo's `image.rle` and the badge's `shape.rle` are intersected separately with that shared coverage.

Native CPU execution at `4d5810cf` verifies the task identities, clip counts `[1, 1]`, span values, and output pixels. One badge coverage sample is `(100 × 203 + 255) >> 8 = 80`. No mask compositor is allocated. A second fixture shifts the same clipper's center to x=7.25.
