# Core2026 > Engine > CPU Engine - 14

Picture는 Loader가 반환하는 데이터에 따라 Vector와 Bitmap 경로로 나뉩니다. 이 글에서는 Bitmap의 화소가 준비되고, 변환·Sampling·Clip을 거쳐 Surface에 기록되는 과정을 살펴봅니다.

| 입력 | Loader의 결과 | 렌더링 경로 |
| --- | --- | --- |
| SVG, Lottie | `Paint*` tree | 자식 Paint의 `update()`·`render()`에 위임 |
| PNG, JPG, WebP, raw pixels | `RenderSurface*` | `SwImageTask`에서 준비 → Image Raster |
